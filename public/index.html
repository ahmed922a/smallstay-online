Step 1 — Set up your hotel

This is the first step, before the owner account. The hotel name, price and rooms you enter here are used everywhere in the app. Floors and room numbers are set here — to change them later, back up your data, then start fresh and run the wizard again.

Rooms are numbered by floor: floor 1, 10 rooms = 101–110; floor 2 = 201–210, and so on.

First use — create your owner account

There is no default password. Choose your own owner username and PIN (at least 4 characters). PINs are stored only as a salted hash — never in plain text. Write them down somewhere safe.

Sign in — real hotel data

Sign in with the username and PIN made on this computer. The owner makes staff accounts inside the app (Team page).

Who is signing in?

Tap your name, then type your PIN.

Daily Report

Reporting convention: a “night” belongs to the date the night starts. “Revenue for this date” counts one night's agreed amount for each room occupied that night — never the whole multi-night stay total. Check-ins and check-outs are listed by the date they actually happened.

Staff accounts — sign-in usernames & PINs

Owner or Manager creates each worker's account here. Each person signs in with their own username and PIN. PINs are stored only as salted hashes and are never shown in lists or exports. Owner and Manager always use the full app; working staff start in Simple mode — only Owner/Manager can switch a worker to Full mode.

Team — who sees what

Working staff in Simple mode see only their own work, with a button to view all rooms. Full mode still respects each role's permissions.

Hotel floor structure

Guest rooms are set in the Setup Wizard. The floors, room count and room numbers for this hotel are shown in Settings once the hotel is set up.

About SmallStay

SmallStay v1.7 online — $29/month flat, no per-room fee. Works offline. No Booking.com sync. Data is saved on the server and works on any device — use Backup to keep a safe copy.

Room price

Default price per room per night. Changing it affects new check-ins only — amounts already agreed on existing stays never change.

Your data on this computer

Real hotel data is saved in this browser, on this computer, and stays after you close the file, close the browser, and reopen the file later. It does not sync to another computer, phone, or browser. Clearing this browser's data, or using a different browser or computer, will not have the same data — use Backup below to move it or keep a safe copy.

Honest security note: PINs are stored as salted hashes, never in plain text, and every action checks the signed-in role inside the operation itself, not just by hiding buttons. But a standalone browser file cannot be tamper-proof against someone who controls this computer — they could edit the file or its saved data. For shared, multi-computer production use with real enforcement, the hotel needs a server version where authorization is checked on the server.

Backup & Restore

Download backup saves all real hotel data — rooms, room types, guests and stays, cleaning, inspections, maintenance, staff accounts (hashed PINs only) and settings — as one versioned file. Restore validates the file first and replaces the real data only if the file is fully valid. Backup and restore require a signed-in Owner or Manager and are disabled in demo.

This replaces ALL real hotel data on this computer with the backup. Your demo is not affected.
